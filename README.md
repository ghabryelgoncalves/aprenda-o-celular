# Aprenda o Celular

> Projeto acadêmico desenvolvido no curso de Análise e Desenvolvimento de Sistemas, com foco em acessibilidade digital, usabilidade e desenvolvimento front-end.

## Sobre o projeto

O **Aprenda o Celular** é uma plataforma web desenvolvida como parte de um projeto acadêmico, com o objetivo de auxiliar pessoas com pouca familiaridade com tecnologia a compreender e utilizar recursos básicos de um celular.

A proposta é apresentar os conteúdos de forma simples, organizada e intuitiva, permitindo que o usuário aprenda no seu próprio ritmo.

O projeto foi desenvolvido com foco em **experiência do usuário, acessibilidade, responsividade e aplicação prática de conceitos de desenvolvimento web**, utilizando HTML, CSS e JavaScript.

## Objetivo

O objetivo do projeto é desenvolver uma solução digital que facilite o acesso ao conhecimento tecnológico para pessoas que possuem pouca familiaridade com recursos e funcionalidades de smartphones.

A plataforma aborda temas como:

* Ligações telefônicas;
* Mensagens pelo WhatsApp;
* Utilização da câmera;
* Conexão com redes Wi-Fi;
* Ajustes de volume e brilho;
* Instalação e utilização de aplicativos;
* Identificação e prevenção contra golpes;
* Perguntas frequentes.

## Contexto acadêmico

Este projeto foi desenvolvido como atividade acadêmica durante a formação em **Análise e Desenvolvimento de Sistemas**, aplicando conhecimentos relacionados ao desenvolvimento front-end, estruturação de interfaces, responsividade, usabilidade e interação com o usuário.

O projeto possui finalidade **educacional e acadêmica**, não sendo destinado atualmente à utilização como produto comercial.
